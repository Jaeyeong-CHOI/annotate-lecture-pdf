# 쪽별 명세 형식 (spec/<이름>/*.json)

한 파일에 여러 쪽을 담는다. 키는 쪽 번호(문자열), 값은 그 쪽의 주석이다. 같은 쪽을 두 파일에 쓰지 않는다. `<이름>`은 원본 PDF 파일 이름에서 확장자를 뺀 것이다.

```json
{
 "12": {
  "tr": [
    {"p": "p1", "ko": "물리 메모리"},
    {"p": "p2", "ko": "물리 메모리는 바이트의 배열이다"},
    {"p": ["p27", "p29"], "ko": "두 문단으로 쪼개진 한 문장의 번역"}
  ],
  "hl": [
    {"t": "array of bytes"},
    {"t": "load", "p": "p4"}
  ],
  "notes": [
    {"at": "array of bytes", "ko": "메모리 접근은 결국 '주소를 주고 읽거나 쓴다'뿐이다. 이 **주소**를 누가, 언제 바꿔 주느냐가 주제."},
    {"at": "r1", "ko": "그림 영역 전체를 가리키는 필기"},
    {"at": "p8", "kind": "tr", "ko": "그림 속 레이블의 번역(파란 글씨로 나온다)"},
    {"at": null, "pos": "b", "ko": "가리키는 대상이 없는 필기"}
  ],
  "sum": "물리 메모리 = 바이트 배열. 프로그램은 주소를 지정해 읽고(load) 쓴다(store)."
 }
}
```

실제로 돌아가는 예는 `examples/spec/sample/01.json`에 있다. 본문 키 `ko`는 `text`로 써도 된다.

## tr — 번역 (파란 글씨)

- `p`: `layout/<이름>.txt`의 문단 id. 한 문장이 두 문단으로 나뉘어 있으면 배열로 묶는다.
- 배치는 자동이다. 한 줄짜리 문단은 줄 오른쪽, 그 밖에는 문단 바로 아래에 놓이고, 자리가 없으면 ①② 번호를 달아 근처에 모은다(`info_tr_panel`).
- `pos`: `"r"`(오른쪽 우선) 또는 `"b"`(아래 우선). `box`: `[x, y, 폭]`으로 직접 지정. `fs`: 글자 크기 상한.
- 번역문 안에 번호 기호(①②)를 직접 쓰지 않는다. 패널 번호와 겹친다.

## hl — 강조 (노란 형광펜)

- `t`: 쪽에 실제로 있는 원문 구절(대소문자 무관). `p`를 주면 그 문단 안에서만 찾는다.
- `p` 없이 쓰면 본문에 있는 모든 일치 구절이 칠해진다(제목 줄은 제외). 짧은 단어는 엉뚱한 곳까지 칠해지므로 `p`로 좁힌다.
- 찾지 못하면 `hl_not_found` 경고가 난다. layout 텍스트에서 구절을 그대로 복사해 쓴다.

## notes — 필기 (빨간 글씨 + 화살표)

- `at`: 가리킬 대상. 문단 id(`"p3"`), 그림 영역 id(`"r2"`), 원문 구절(`"page frame"`), `{"t": 구절, "p": 문단, "n": 몇 번째}`, 좌표 `[x0, y0, x1, y1]`, 또는 `null`.
  - 구절을 가리키면 그 구절에 빨간 밑줄이, 영역을 가리키면 빨간 점선 테두리가 생긴다.
  - 화살표가 95pt보다 길거나 다른 내용을 가로지르면 화살표 대신 같은 번호의 빨간 배지 한 쌍으로 바뀐다.
- `ko`: 본문. `**굵게**`와 `\n` 줄바꿈을 쓸 수 있다.
- `kind`: 생략하면 빨간 필기. `"tr"`만 파란 글씨(그림 레이블 번역용). 그 밖의 값(key, why, ex, warn, exam)은 모두 같은 빨강이다.
- `pos`: 대상 기준 선호 방향 `r|l|t|b`. `box`: `[x, y, 폭]` 직접 지정(겹침 검사 없음). `fs`: 글자 크기 고정. `label`: 앞에 붙일 굵은 머리말. `arrow: false`: 화살표 생략.
- 놓을 자리를 못 찾으면 `unplaced_note` 경고가 난다. 문장을 줄이거나 필기 수를 줄인다.

## sum — 쪽 한 줄 정리

'정리'로 시작하는 빨간 글씨. 쪽 아래 빈 줄 → 제목 오른쪽 → 그 밖의 빈자리 순으로 놓인다. 두 줄을 넘지 않게 쓴다.

## 수식 표기

번역·필기·정리 본문 어디서나 쓸 수 있다.

| 표기 | 결과 | 예 |
|---|---|---|
| `_{…}` | 아래 첨자 | `log_{2} n`, `a_{i}` |
| `^{…}` | 위 첨자 | `2^{k}`, `n^{2}` |
| `~{…}` | 윗줄(overline) | `~{A ∪ B}` |

기호(∑, ∈, ≤, ⌈ ⌉, → 등)는 유니코드 문자로 그대로 쓴다. 본문 글꼴에 없는 글자는 기호용 글꼴로 자동 대체된다. 첨자 안의 공백은 무시된다.

## 좌표

단위는 pt, 원점은 쪽 왼쪽 위. `img/<이름>/pNN.png`는 1pt가 약 1.39px이므로 pt = px × 0.72.

쪽 크기가 일반 슬라이드와 많이 다른 PDF(Beamer, Keynote 등)는 높이 540pt에 맞춘 배치 좌표계를 쓴다. `layout`의 좌표, 쪽 이미지, 명세의 `box`·`at` 좌표가 모두 이 좌표계이므로 따로 환산할 필요가 없다. 배치 좌표계의 크기는 `layout/<이름>.txt` 첫 줄에 적혀 있다.

## 경고 종류

| 경고 | 뜻 | 조치 |
|---|---|---|
| `no_spec` | 그 쪽의 명세가 없다 | 최소한 `sum`을 쓴다 |
| `par_not_found`, `region_not_found` | 없는 문단·영역 id | layout에서 id를 다시 확인한다 |
| `hidden_par` | 원본에서 가려진 문단을 가리켰다 | 명세에서 뺀다 |
| `hl_not_found`, `text_not_found` | 구절이 쪽에 없다 | layout의 글자를 그대로 복사한다 |
| `unplaced_note`, `unplaced_tr`, `unplaced_sum` | 놓을 빈자리가 없다 | 문장을 줄이거나 개수를 줄이거나 `box`로 지정한다 |
| `too_many_panel` | 번호 패널로 밀린 번역이 20개를 넘는다 | 번역을 합치거나 `box`로 지정한다 |
| `dark_page` | 배경이 어두운 쪽 | 빈자리 판정이 부정확하니 눈으로 확인하고 `box`로 지정한다 |
| `bad_kind` | 모르는 `kind` 값 | 생략하거나 `tr`로 쓴다 |
| `info_tr_panel` | 번역 일부를 번호 패널로 모았다 | 조치 불필요(보기 나쁘면 `pos`·`box` 조정) |
